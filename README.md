## Автор
**Имя:** Дана Кармантаева (Karmantaeva Dana)

## Тема проекта
Лендинг для сервиса/магазина экологичных товаров для дома и ухода за собой **EcoLife**. Проект создан в рамках учебного задания (Неделя 2: HTML5, семантическая разметка, формы, доступность и адаптивность).

## Что сделано в проекте:

1. **Структура и семантика (HTML5):**
   - Использованы обязательные семантические теги: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
   - Соблюдена правильная иерархия заголовков (`<h1>`, `<h2>`, `<h3>`).
   - Настроена секция `<head>`: добавлены `title`, `meta description`, `viewport` для адаптивности и `favicon`.
   - Для всех изображений прописаны понятные атрибуты `alt` для accessibility и SEO.

2. **Форма обратной связи:**
   - Реализован блок контактов с валидной HTML5-формой.
   - Поля ввода (`Имя`, `Email`, `Сообщение`) имеют парные теги `<label>` с корректными атрибутами `for`.
   - Для обязательных полей задан атрибут `required`.

3. **Стилизация и адаптивность (CSS3):**
   - Верстка выполнена вручную на чистом CSS3 без шаблонов, фреймворков (Bootstrap) и конструкторов.
   - Разметка сетки выполнена с использованием Flexbox.
   - Настроена адаптивность под мобильные устройства (**375px**) и десктопные экраны (**1280px**).
